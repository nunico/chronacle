# Chronacle Website and Manual Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a production-quality static Chronacle website with an informal bilingual landing page and a searchable English/German user manual.

**Architecture:** Add `apps/website` as a SvelteKit static-adapter workspace package. Markdown manual pages compile through mdsvex into a typed content registry, and Pagefind indexes the prerendered English and German pages after the SvelteKit build. The root landing page switches copy in place without persistence; manual routes remain explicit under `/en/manual` and `/de/handbuch`.

**Tech Stack:** SvelteKit 2, Svelte 5 runes, TypeScript 6, Vite 8, Tailwind CSS 4, mdsvex, Pagefind, Vitest, Testing Library, Playwright, axe-core, pnpm 11.

---

## Scope and implementation order

This is one integrated site, but implementation is deliberately layered:

1. package and static-build foundation;
2. content registry and locale-safe routing;
3. Chronacle brand shell and landing page;
4. manual reference layout and search;
5. English content migration and German translation;
6. OGL treatment, accessibility, browser tests, and repository gates.

Each task ends in a working commit. Do not begin the next task while the named verification command is failing.

- [ ] **Step 3: Implement the locale API**

```ts
export type Locale = "en" | "de";
export type ManualSegment = "manual" | "handbuch";

const manualSegments: Record<Locale, ManualSegment> = {
  en: "manual",
  de: "handbuch",
};

export function browserPreferredLocale(languages: readonly string[]): Locale {
  return languages[0]?.toLowerCase().startsWith("de") ? "de" : "en";
}

export function manualBase(locale: Locale): string {
  return `/${locale}/${manualSegments[locale]}`;
}

export function isManualRoutePair(locale: string, segment: string): boolean {
  return (
    (locale === "en" || locale === "de") && manualSegments[locale] === segment
  );
}

export function routeLocale(pathname: string): Locale {
  return pathname === "/de" || pathname.startsWith("/de/") ? "de" : "en";
}
```

- [ ] **Step 4: Add route matchers and reject mismatched pairs in page load**
